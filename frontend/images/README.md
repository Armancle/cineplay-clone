# CinePlay Images Directory

This directory is designated for storing all local image assets used throughout the CinePlay platform, including:

- **posters/**: Movie and game cover posters.
- **hero/**: Hero banner backgrounds and slider graphics.
- **avatars/**: User and developer profile photos.
- **icons/**: Custom badges, SVG icons, and graphic assets.

Feel free to add your `.jpg`, `.png`, `.webp`, or `.svg` files here and reference them in HTML/CSS (e.g., `images/poster-1.jpg`).
